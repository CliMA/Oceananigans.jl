## Notes

- Reproduce: `julia --project validation/split_stepping_ffsl/biogeochemistry.jl` (CPU, Julia 1.12).
- Total nitrogen ∫σ(N+P+Z+D) dV is conserved to ≤ 2.5e-15 for every N and vertical scheme.
- Positivity: with first-order upwind (adaptive implicit) vertical advection the NPZD tracers stay positive up to
  N = 16 (C ≈ 1.2). At N = 32 (C ≈ 2.4) the minimum is −3.0e-2 with AVID cfl = 0.5 and −1.1e-3 with cfl ≤ 0.2
  (a more implicit vertical step), and at N = 64 (C truncated at 4) −8.8e-2 independent of cfl.
  The residual undershoot comes from the horizontal FFSL step itself: a passive step-function tracer (0.5 / 1e-3) in
  the same gyre undershoots to −3.1e-4 at C ≈ 2.4, identically for the split N = 32 run and for an unsplit FFSL run
  with Δt = 96 minutes. The dimensionally split Lin–Rood scheme with the CW monotone limiter is not strictly
  positivity-preserving at C > 1 in a two-dimensional flow (a Workstream B property). Nothing is clipped.
- With WENO5 vertical advection D goes strongly negative (≈ −19) already at N = 1; an unsplit all-WENO5 model (no FFSL,
  no splitting) gives −34 in the same setup: WENO5 vertical advection of the sinking detritus next to the immersed
  bottom is not positivity-preserving (pre-existing, unrelated to this work).
